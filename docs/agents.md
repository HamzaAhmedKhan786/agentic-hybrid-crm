# Agent catalog

| Agent | Purpose | Governed output |
|---|---|---|
| CRM assistant | Grounded CRM questions | Answer, citations, task proposal |
| Qualification | Fit, intent and timing | Lead-score proposal |
| Account research | Evidence-backed brief | Research/task proposal |
| Pipeline risk | Deal risk and next action | Follow-up proposal |
| Email | Factual outreach draft | Draft/send approval |
| Data quality | Duplicates and gaps | Merge/update proposal |
| MCP | Tool selection | Read result or approval request |

Every run stores objective, model, retrieval/model steps, usage, latency and recommendations. Confidence is advisory, never authorization.
